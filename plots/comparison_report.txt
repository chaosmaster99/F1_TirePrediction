EVALUATION METHODOLOGY:
--------------------------------------------------
Instance-level: model predicts per lap-row, compared to actual
  lap time delta. Larger test set, finer granularity.
Curve-level: model forecasts degradation curves per stint, compared
  to averaged actual degradation. Comparable across TS models.

NOTE: Instance and Curve metrics are NOT directly comparable.
      XGBoost/LSTM instance RMSE << ARIMA/VAR/Hybrid curve RMSE
      is expected due to different evaluation granularity.

MODEL DESCRIPTIONS:
--------------------------------------------------
1. ARIMA: Autoregressive Integrated Moving Average [Curve]
   - Time series model on averaged per-compound degradation curves
   - Models degradation as an autoregressive process

2. VAR: Vector Autoregression [Curve]
   - Multivariate model treating all compound curves as a system
   - Captures cross-compound dynamics and lead-lag relationships

3. XGBoost: Gradient Boosted Decision Trees [Instance]
   - Feature-based ML model capturing non-linear interactions
   - Considers compound, circuit, driver effects simultaneously
   - Also includes pit stop binary classifier (F1 score)

4. LSTM: Long Short-Term Memory Neural Network [Instance]
   - Deep learning model for sequential data
   - Autoregressive per-step prediction

5. Hybrid (ARIMA+XGBoost): Residual Stacking [Instance]
   - ARIMA base prediction + XGBoost residual correction
   - Combines time-series structure with feature-based learning
